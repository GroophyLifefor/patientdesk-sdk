    Upgrading to 0.2.2

    This guide covers patientdesk-sdk 0.2.1 to 0.2.2. The release has no breaking API or type change. It adds the streaming STT turn-taking knob that PatientDesk documented.

    At a glance

    • transcribeStream() accepts a new minSilenceMs start option, sent as min_silence_ms in the start frame.
    • It sets how many milliseconds of silence close a sentence, from 200 to 2000. A value outside that range returns bad_request.
    • Omitting it keeps the server default, so existing code and types are unchanged.

    Turn taking

    A streaming final arrives after the server sees the configured silence. The default is about 500 ms. minSilenceMs changes it per connection:

    const stream = pd.audio.transcribeStream(
  { final: (text) => console.log(text) },
  { sampleRate: 16000, eagerFinal: true, minSilenceMs: 450 },
);

    A shorter silence answers sooner but treats pauses inside a sentence as the end. PatientDesk reports that on Turkish speech, 250 ms split a sentence in the middle. For phone calls, start at 400–500 ms and measure on your own calls.

    eagerFinal starts its decode at a 400 ms pause, so a minSilenceMs of 400 or less gains nothing from it. See Streaming for the full option table.

    Backward compatibility

    • minSilenceMs is optional and the SDK sets no default, so the request is identical when it is omitted.
    • The SDK does not validate the range locally. A value outside 200–2000 is sent as-is and the server answers bad_request.

    Verifying the upgrade

    npm run typecheck
npm test
