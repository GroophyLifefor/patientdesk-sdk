    Upgrading to 0.2.3

    This guide covers patientdesk-sdk 0.2.2 to 0.2.3. The release has no breaking API change. It follows two PatientDesk changes: barge-in on the TTS WebSocket, and prepaid credit with a new 402 error.

    At a glance

    • speech.socket() returns a new cancel() that stops the oldest unfinished speak and keeps the connection open.
    • speechEnd carries canceled: true when a cancel stopped that speak.
    • 402 insufficient_balance is never retried, and PatientDeskError has an isInsufficientBalance getter.
    • SpeechSocket.speak() is typed as returning Promise<void>, which it already did at runtime.

    Barge-in

    When the caller talks over the agent, send one cancel for every speak that has no speech_end yet, then drop buffered audio until the next speechStart:

    let unfinished = 0;
const socket = pd.speech.socket({ speechEnd: () => unfinished-- });
const say = (input: string) => {
  unfinished++;
  return socket.speak({ input });
};

// The caller started talking:
for (let i = 0; i < unfinished; i++) socket.cancel();

    A speak is charged once its speech_start is sent, even when a cancel cuts it short. One canceled while still queued is not charged. speak() and cancel() reach the server in call order. See Streaming.

    Prepaid credit

    PatientDesk now draws usage from prepaid credit. When it runs out, Alania and Duyu requests return 402 insufficient_balance. antalia-mini stays free.

    try {
  await pd.speech.create({ input: "Merhaba" });
} catch (err) {
  if (err instanceof PatientDeskError && err.isInsufficientBalance) {
    // Add credit or turn on automatic top-up; retrying will not help.
  }
}

    429 quota_exceeded is now a monthly ceiling against abuse rather than the billing limit. It is still never retried.

    Backward compatibility

    • cancel() and canceled are additions. Code that does not use them behaves as before.
    • Before 0.2.3, a 402 with a Retry-After header could be retried. It now fails at once.

    Verifying the upgrade

    npm run typecheck
npm test
